# MyPortal

`MyPortal` is an AI Agent Harness project with a FastAPI backend and a Vue frontend named `portal-front`.

## Backend

Run the backend API:

```bash
uv run --project D:\workspace\openharness\MyPortal myportal-api
```

## Frontend

Run the Vue frontend:

```bash
cd D:\workspace\openharness\MyPortal\portal-front
npm run dev
```

## LLM

The backend supports `GLM-5` and loads local `.env` configuration automatically from the project root when present.
